# Reference library

Use in Phase 1 when the user has no references. Propose 4 to 6 that fit the project's mood, then capture screenshots with `scripts/capture.mjs` and analyze them. Always look at the live site before relying on a note here; sites change. Add new favorites to this file over time; this library is part of what makes Sonder better with every project.

## Warm, human, editorial
- **wisprflow.ai**: serif display type with an italic turn, small tracked uppercase labels, product output used as decoration, pinned stepped sections, blurred photography in fixed frames.
- **goodside.studio**: restrained brand-studio layouts, strong case-study presentation.

## Bold, structural, company-as-system
- **steven.com**: heavy condensed caps, tiny parenthetical labels with live city clocks in the nav, the company's structure used as navigation, full-screen menu overlay.
- **obys.agency**: modernist typography, grid systems and motion; concept-driven studio work.
- **malvah.co**: confident, minimal brand experiences with rhythm and pacing over decoration.

## Product as hero, technical and tactile
- **ghost.ai**: now a hardware launch page ("Core"). Useful for the product name spread across the full screen width with the object standing in front of the letters, and quiet rows of facts in small boxed labels. Its earlier warm-grey teardown page is gone, so check the live site before relying on older notes. For the teardown technique itself, see Technical illustrations in `concepting.md`.
- **14islands.com**: playful interactive experiments alongside client work (Blobmixer).

## Immersive 3D and WebGL
- **lusion.co**: real-time 3D storytelling, ambitious studio site.
- **immersive-g.com**: high-end immersive storytelling for luxury brands.
- **exoape.com**: narrative scroll experiences, studio and anniversary sites.
- **utsubo.com**: engineering-led WebGPU and real-time 3D.
- **rhumb.co**: spatial web experiences that feel like places; a two-person studio.

## Type-led and Swiss
- **studio-size.com** / exat.hottype.co: typography as the interactive subject, scroll and cursor-reactive type.
- **garden-eight.com**: playful but precise Japanese studio craft.
- **2xa.studio**: code-driven, computational identity.

## Motion and polish benchmarks
- **landonorris.com**: high-energy personal brand with heavy motion.
- **pear.no**: smooth, polished motion and transitions.
- **basement.studio**: bold studio site with playable experiments, startup clients.
- **unseen.co**: brand, digital and motion studio with long award history.
